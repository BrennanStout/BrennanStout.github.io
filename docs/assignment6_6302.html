###Tweets: ##Background: This summit was a notable meeting between the Chinese and US leaders to try and defuse some of the tensions which had been building during that time. It resulted in generally a favorable aspect between the two leaders. In the comparisons of the tweets which came out about that time, it is not overly surprising that the Xi administration linked to terms related to China more and the US administration linked to terms related to the US. The interesting part comes from the comparison of the use terms which came out of the summit, even as the tweets tend to be a rather limited view of the situation and biased to a given topic as the tweets gathered were all in English. From the documents it can be seen that both sides were using generally positive terms in regards to the situation, like relationship compromise and deepening. However, amusingly China referred to itself more than anything other while the US had nations as their most used term.

###Quantitative Text Analysis In the comparison of the presidential inaugural addresses, this is being done on length, word diversity, and readability. Additionally, these addresses can be understood on the cosine similarity and keyness by party. In terms of length, which can be can be understood in the number of tokens needed to process the address. However, despite the want of politicians to talk the number of tokens has not changed overly much across all the addresses. The one which has changed greatly is that of the word choice and complexity. As the decades have moved, and the understanding of who the address is aimed at has changed there is a notable drop in the complexity of the language being used measured in US grade level. Even despite this, there are still a lot of consistent words which will continue to be used between addresses and even addresses of a similar era will remain generally consistent. For example, topics like jobs or drugs will be usually relegated to more modern speakers, but terms like government or people are very often present with good reason. These are notable and well crafted address which are meant to be a summation of nation concerns and the beginning of some era of change, but these sorts of consistencies between addresses point to an amusing level of irony behind that particular concept.

download_log <- lapply(seq_along(all_records), function(i) {
  item <- all_records[[i]]
  pkg_id <- item$packageId
  
  pdf_url <- if (!is.null(item$download$pdfLink)) {
    item$download$pdfLink
  } else {
    paste0("https://api.govinfo.gov/packages/", pkg_id, "/pdf")
  }
  
  file_name <- paste0(pkg_id, ".pdf")
  dest_path <- file.path(save_dir, file_name)
  if (file.exists(dest_path) && file.size(dest_path) > 0) {
    status <- "Already Downloaded"
  } else {
    status <- tryCatch({
      request(pdf_url) |>
        req_url_query(api_key = api_key) |>
        req_perform(path = dest_path)
      "Success"
    }, error = function(e) {
      conditionMessage(e)
    })
    Sys.sleep(0.2)
  }
  
  data.frame(
    index        = i,
    package_id   = pkg_id,
    date_issued  = if (!is.null(item$dateIssued)) item$dateIssued else NA_character_,
    title        = if (!is.null(item$title)) item$title else NA_character_,
    collection   = if (!is.null(item$collectionCode)) item$collectionCode else "CPD",
    pdf_url      = pdf_url,
    file_path    = dest_path,
    size_mb      = if (file.exists(dest_path)) round(file.size(dest_path) / (1024^2), 2) else NA_real_,
    status       = status,
    stringsAsFactors = FALSE
  )
})

biden_regex <- "\\b(biden|joe|potus|whitehouse|washington|us|u\\.s|usa|america|american)\\b"
xi_regex    <- "\\b(xi|jinping|china|chinese|beijing|ccp|prc)\\b"

raw_texts <- tolower(as.character(tweet_corpus))
has_biden <- str_detect(raw_texts, biden_regex)
has_xi    <- str_detect(raw_texts, xi_regex)

docvars(tweet_corpus, "admin_focus") <- case_when(
  has_biden & !has_xi ~ "Biden_Admin",
  !has_biden & has_xi ~ "Xi_Admin",
  has_biden & has_xi  ~ "Bilateral",
  TRUE                ~ "Other"
)
