—- 5. The question this script exists to raise ————————— Compare 2 and 3. Same concept, two data-generating processes: - Wikipedia: edited by volunteers, sourced from many places, no schema, no versioning, no uncertainty, changes without notice - World Bank: one compiler, documented methodology, stable indicator code Scraping was the wrong tool here. Knowing when it is the only tool is the skill this course is actually teaching.

The time stamps on the World Bank data is probably the most imporant part of understanding the scraping, this gives a point of reference to check the data against. While Wikipedia is a decent source, to get those same timestamp if would likely require scraping (or using the api) of each bank being referenced in the table. As is stated, scraping is best when it is the only tool available. APIs or other data access points get around all of those messy data issues which come from even the most successful scraping attempts.

AI note Gemini was used for dealing with the tibble and visualizations.
